# STOCKS-MANAGEMENT

Store stock management for Figaro Culinary Group stores. It tells each store how much dough, carbo and palabok to order or make, and on which day, so every item is used inside its usable days and spoilage and waste go down. The calculation is automatic and the store can adjust it.

**Status:** planning. No product code yet. Start with [docs/README.md](docs/README.md) once the documentation pull request is merged.

**Stack (planned):** Cloudflare Worker and D1 on the free tier, React with Vite as an installable PWA, deployed from GitHub Actions.

This repository is private.
